## 双端兼容（Keynote + PowerPoint）

可见层全部是原生形状与文本：矩形、圆角矩形、椭圆、直线，没有图片化的图表。
11 个原生 OOXML 图表与对应的嵌入工作簿保留在文件里作为可编辑数据载体，被同一数据绘制的矢量层覆盖；
因此两端渲染结果相同，而图表数据仍可在 PowerPoint 里打开编辑。

`compat.py` 修掉 pptxgenjs 4.0.1 留下的三处不规范，这三处是双端出问题的实际来源：

1. 幻灯片 rels 用绝对部件名 `/ppt/charts/chartN.xml` —— Keynote 对绝对 Target 不稳定，改为 `../charts/`。
2. 二维柱/折线图在绘图区声明了第三个 `axId`，但文件里只有 `catAx` 与 `valAx` —— **PowerPoint 会据此判定文件损坏并弹出修复提示**，必须删掉。
3. 分类缓存用 `multiLvlStrRef` —— 单层分类改回标准 `strRef`，两端都稳。

字体：正文每个 run 都显式写 `latin` / `ea` / `cs` = PingFang SC。PingFang SC 是 macOS 自带、Windows 不自带，
所以在 Windows PowerPoint 上会发生字体替换。替换本身不影响中文显示，但会改变字距，可能撑破文本框；
为此所有文本框都带 `fit:'shrink'`（`<a:normAutofit/>`），溢出时自动缩字号而不是跑版。
若要在 Windows 上得到和 Mac 完全一致的排版，把 PingFang SC 装进 Windows 字体目录即可。

```bash
  'Anthropic_2万亿IPO的背后_编码模型与AGI_Claude.pptx'
# 导入 Keynote 前，先关掉所有已打开文档（见下方注意），再导出 KEY 与 PDF，然后：
swift render_pdf.swift 'Anthropic_2万亿IPO的背后_编码模型与AGI_Claude.pdf' preview
python3 docs.py                # 由 slides.json 与 preview/*.txt 生成两份 md
```

生成器只产出 PPTX 与 slides.json。KEY / PDF / preview 不会自动更新，改完必须重新走一遍 Keynote 导出与渲染。

**Keynote 导出的坑**：若 Keynote 未在运行，`activate` 会触发 macOS 恢复上次的窗口，
此时 `front document` 可能取到上一版的旧文档，导出的 PDF 看上去是新的（时间戳新），内容却是旧的。
导出脚本必须先 `close every document saving no`，再 `open`，并在日志里打印文档名与页数自检。
